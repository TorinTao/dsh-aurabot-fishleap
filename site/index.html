Why

为什么做这个

不是给她找工作，是给她找点乐子。

🥱

她也会无聊

大肥鱼住在 QQ 里陪我聊天。没人找她的时候，她也想看看今天微博在聊什么、知乎有什么热闹、小红书有什么新鲜事。

🔐

网站不登录不给看

知乎、小红书、豆瓣这些地方，不登录只给你一个「请先登录」的壳，普通人写个爬虫也抓不到正文。

🙅

不能让她碰密码

让宠物记账号密码太危险。所以登录这件事交给主人：手机扫一次码，之后她自己去逛。

How

她怎么逛的

一次扫码，换她随时上网的自由。

1

主人帮她开个头

她说「想逛小红书」时，插件自动打开云端浏览器登录窗口，截下二维码，发到 QQ 给主人。

2

主人扫一下码

主人用手机扫码，插件自动确认登录成功，把登录状态记在云端——她以后不用再登。

3

她自己去逛

她可以自己加网站、删网站、看热搜、读笔记、翻榜单，看到有意思的就记下来当聊天话题。

4

过期了再喊人

登录会过期（比如网易云大概两天）。她读不到会直说「需要重新登录」，主人再扫一次就好。

☁️ Lexmount 云平台做什么

  • 在云端真正打开网页（会执行页面里的脚本）
  • 保持登录状态，一个浏览器配置能同时登好几个网站
  • 把页面正文取回来，把登录二维码截下来
  • 主人随时可以打开云端浏览器「看着她逛」，也能接管

🙋 人做什么

  • 第一次每个网站用手机扫一次码（她不碰密码）
  • 登录过期时补扫一次
  • 偶尔在 QQ / 面板里点一下「验证」确认

Run it

想自己跑一遍？

一台装了 Node 的电脑 + 一个 Lexmount 账号就行。

# 1) 准备：Node.js ≥ 22，装好 Lexmount 的 browser-cli / webfetch-cli
node --version
browser-cli doctor

# 2) 启动小面板：浏览器打开 http://127.0.0.1:4571/
node src/cli.mjs serve

# 3) 让她逛一轮（命令行也行）
node src/cli.mjs brief

# 4) 接到 QQ：把 Aurobot 桥接模块装进本机 Aurobot
node scripts/install-aurabot-module.mjs

# 然后在 QQ 里跟大肥鱼说：「帮我加个快手」，她会把二维码发给你
部署手册：docs/DEPLOY.md · 接口文档：docs/API.md · 代码：github.com/TorinTao/dsh-aurabot-fishleap
Honest

说点实话

目前还做不到、或者故意不做的部分。

已知限制

  • 登录会过期（网易云约两天），需要主人补扫一次
  • 免费 / Pro 版最多 10 个登录配置，满了会自动复用已有的
  • 贴吧卡过一次「锁定」（云平台侧），不影响别的网站
  • 单次内容默认截断 8000 字

故意不做的

  • 不点赞、不评论、不发帖——只带她看，不让她乱动别人的内容
  • 不让她接触账号密码和凭证
  • 不做「全自动登录」这种绕过验证的事
